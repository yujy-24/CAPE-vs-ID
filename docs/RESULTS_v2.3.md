# 动作条件表征学习对比实验：结果汇总（2026-11-26）

在 LIBERO 仿真操作数据上，以统一平台（同一冻结 DINOv3 ViT-B/16 骨干、同一数据、等步数训练）比较四种表征训练方案与不训练基线。40 个任务按任务级划分（32 训练 / 8 留出），下列指标除注明外均在 8 个留出任务上测得；本实验为表征层研究，不含闭环成功率。评测取两个角度：动作条件检索（动作 → 后果）与动作解码探针（帧对 → 动作）。

## 1. 训练方案

| 方案 | 训练目标 |
|---|---|
| 基线 | 不训练，直接使用 DINOv3 输出 |
| 前向预测 | 由（当前画面，动作序列）预测终点画面特征，余弦损失；"世界模型"式目标 |
| CAPE（官方代码逐行移植） | 动作条件对比学习：同一画面执行不同剩余动作、经不同中间状态到达同一终点画面；将"中间画面＋剩余动作"映射为向量，与终点特征构成正对、与批内其他样本构成负对 |
| 逆动力学 | 由相邻两帧特征回归其间 7 维动作 |
| CAPE 消融版 | 同 CAPE，仅去除"动作替换负例"（将支路动作替换为批内其他样本的动作并推远其结果） |

## 2. 动作条件检索（主指标）

协议：给定中间画面与剩余动作序列，模型输出预测向量，在同一任务的候选库（该任务全部中间与终点状态向量，132–370 个）中检索该动作序列实际到达的状态；995 个查询，固定种子生成、各方案共用。指标：Hit@1 为正确答案居首位的比例（随机 ≈0.4%），Hit@5 为进入前五的比例，MRR 为名次倒数的均值；macro 列先按任务计算、再对 8 个任务平均。

| 方案 | Hit@1 | Hit@5 | MRR | macro Hit@1 | macro Hit@5 |
|---|---|---|---|---|---|
| **CAPE 消融版** | **0.2533** | **0.5407** | **0.3896** | **0.2880** | **0.5866** |
| CAPE | 0.1920 | 0.4492 | 0.3192 | 0.2101 | 0.4833 |
| 基线 | 0.1246 | 0.3317 | 0.2302 | 0.1102 | 0.3049 |
| 前向预测 | 0.0482 | 0.1698 | 0.1176 | 0.0507 | 0.1858 |
| 逆动力学* | 0.0080 | 0.0412 | 0.0388 | 0.0095 | 0.0521 |

\* 逆动力学模型仅接受相邻两帧，无法直接处理动作序列，此处退化为相邻帧打分的近似，仅作诊断参考，不构成公平比较。

CAPE 两版显著高于基线并远超随机水平；前向预测低于基线——能够预测终点特征并不意味着表征可支撑状态检索。消融版高于完整版为本实验最主要的意外结果（见结论 2）。

## 3. 按动作序列时长分层（Hit@1）

| 方案 | 0.2s | 0.4s | 0.6s | 0.8s | 1.0s |
|---|---|---|---|---|---|
| 基线 | 0.386 | 0.099 | 0.067 | 0.036 | 0.023 |
| CAPE | 0.238 | 0.225 | 0.159 | 0.155 | 0.182 |
| CAPE 消融版（仅测最长档） | — | — | — | — | 0.220 |

短视野（0.2s）下基线凭外观相似性即可占优；视野增大后基线单调坍缩（1.0s 处 0.023），CAPE 两版基本平坦（0.18–0.22）。动作条件的增益集中于长视野，1.0s 处约 8 倍。

## 4. 动作解码探针

协议：在各方案的冻结特征上另行训练多层感知机（相邻两帧特征 → 7 维动作），在留出任务的 9,950 个帧对上报告决定系数 R² 与平均绝对误差 MAE（动作原单位）。R²=1 为完美预测，0 等价于仅输出训练集动作均值，负值表示劣于均值预测。

| 特征来源 | R² | MAE |
|---|---|---|
| 基线（标签打乱对照） | −0.533 | 0.257 |
| 基线 | −0.712 | 0.268 |
| **逆动力学（自带回归头）** | **−0.009**（夹爪维度 +0.161） | **0.198** |
| CAPE | −0.486 | 0.250 |
| 前向预测 | −0.861 | 0.277 |

留出任务的动作分布偏移使各方案 R² 普遍为负；标签打乱对照（−0.533）反高于原始特征（−0.712），表明该指标动态范围有限、绝对值不具解释力，仅取方案间排序——这也是主要结论建立在检索指标上的原因。逆动力学行使用模型自带回归头（不另训探针），排序最优。

对照实验（另一台机器 RTX 4090 上训练）：换随机种子（43）重训得 −0.040 / 0.203，结果可复现；打乱帧-动作对应关系后训练得 −0.118 / 0.217，降幅不足，该项对照不作定论；损失改 L1 得 −0.180 / 0.200，确认默认 L2 为宜。

泛化诊断：同一逆动力学模型在训练任务的新片段上 R² 0.7447 / MAE 0.0966（26 片段、9 任务、2,678 帧对），在 8 个留出任务上 −0.04——所学为任务内动作模式，而非跨任务规律。参照：仅用单帧 0.676，帧序颠倒 0.431，以上一时刻动作为预测 0.95+（动作平滑性所致）。另有一个留出任务夹爪通道疑似标注约定错位（真值均值 0.232 vs 预测 0.843，单任务 R² −0.911）——11-28 已核查：非标注错位，失效为预测均值贴训练先验的纯平移（见实验记录二十节）。

帧替换敏感性诊断（11-28，实验记录二十一节）：固定首帧、替换第二帧（间隔 2–16 帧 / 静态 / 同轨迹随机 / 跨轨迹），预测响应随输入变化量单调增（留出任务上 pred_move 0.15→0.40，随机条件 0.56–0.67），"只猜均值"假说在分布内外均被证伪；留出任务的真实失效模式是**变化检测保留、动作数值映射失效**（gap1 R² 0.287 vs 分布内 0.871；夹爪均值贴先验但方差未坍缩）。

## 5. 表征几何诊断（CAPE 两版）

600 个验证窗口上的余弦相似度统计，不经下游任务：

| 指标（箭头为优方向） | CAPE | 消融版 |
|---|---|---|
| 同画面双支路预测一致性 ↑ | 0.853 | 0.829 |
| 与终点特征对齐度 ↑（两值为双支路各自结果） | 0.406 / 0.413 | **0.547 / 0.540** |
| 动作替换为同任务其他片段后的相似度 ↓ | **0.218** | 0.349 |
| 动作替换为随机噪声后的相似度 ↓ | **0.123** | 0.259 |
| 替换动作的预测更接近正样本的比例 ↓（0.5 为动作盲） | 0.072 | 0.113 |

消融版终点对齐更优（0.547 vs 0.406）而动作敏感性更低（0.349 / 0.259 vs 0.218 / 0.123）：其检索优势来自更干净的对齐，而非更强的动作分辨力。背景：DINOv3 原始特征中时间相邻画面 0.958–0.978、同任务异片段 0.859、跨任务 0.731，外观空间高度压缩，单凭外观无法区分动作后果，此为动作条件训练的动机。

## 6. 训练配置

- LIBERO（20 Hz，已去除空转段）；任务级划分 32 训练 / 8 留出；7,993 训练 / 995 评测窗口。
- DINOv3 ViT-B/16 全程冻结、特征离线缓存，仅训练其上新模块（约 25.2M 参数）。
- 各方案统一 20,000 步、AdamW（lr 1e-4，余弦退火＋预热）、等数据接触量；CAPE 依官方实现（片段分组批 8×4、温度 0.07、5% 步数预热），逆动力学 L2 回归、有效批 16。
- 单卡 RTX 4070，每方案约 90–135 分钟；逆动力学对照在 RTX 4090 上完成，两机骨干权重经 SHA-256 核对逐字节一致。

## 7. 结论

1. 动作-结果对齐目标有效：官方 CAPE 目标移植后，检索显著优于基线（Hit@1 0.192 vs 0.125，约 6σ）。
2. 官方"动作替换负例"在本数据上为负向成分：去除后由 0.192 升至 0.2533（+6.1 个百分点，约 3σ）。推测机制：仿真操作中同一状态的不同动作常到达等价结果，替换负例构成错误监督；官方消融结论来自 DROID 真机数据，该成分具场景依赖性，不宜照搬。
3. 动作信息的价值集中于长视野：1.0s 处 CAPE 系维持 0.18–0.22，基线降至 0.023（约 8 倍）。
4. 逆动力学分布内强、跨任务失效（新片段 R² 0.7447 vs 留出任务 −0.04），所学为任务内模式；前向预测在检索上最差（0.048），会预测终点特征不等于表征可用于检索。
5. 两类监督源各居其位、互不迁移：动作-结果对齐利于检索类下游，帧间动作利于动作解码类下游；监督源应按下游需求选择。
